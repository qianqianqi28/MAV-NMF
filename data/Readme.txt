# Sedimentary geology: Grain-size distributions dataset
Grain-size distributions dataset is on the AppendixBtestdatasets.xlsx. AppendixBtestdatasets.xlsx is from the Appendix B test datasets.xlsx which is from https://github.com/ouczxd/BasEMMA (a part of A basic end-member model algorithm for grain-size data of marine sediments). Compared with Appendix B test datasets.xlsx, AppendixBtestdatasets.xlsx adds the sheets "truebasis" (from the BasicEMs sheet), "test1abundance" and "test1data" (from the Test1 sheet), "test2abundance" and "test2data" (from the Test2 sheet), "test3abundance" and "test3data" (from the Test3 sheet), and "test4data" (from the Test4 sheet).
